# Enterprise: AI-Assistenten produktionsnah erweitern

Die **Enterprise-Phase** erweitert den grundlegenden AI-Assistenten um produktionsnahe Bausteine. Prompts werden als Templates strukturiert, Gespräche erhalten Memory, Tools binden externe Informationen und RAG stellt relevante Dokumente als Kontext bereit. Abschließend wird die Anwendung mit Spring-AI-Testwerkzeugen überprüft.
