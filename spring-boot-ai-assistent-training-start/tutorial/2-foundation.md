# Foundation: Die Basis des AI-Assistenten

In diesem Kapitel entsteht der erste lauffähige AI-Assistent mit Spring Boot und Spring AI. Wir beginnen beim Projekt-Setup und führen anschließend das Chat Model, den Chat Client, einen Web-Controller und eine einfache Benutzeroberfläche zusammen.

Nach diesem Kapitel können Sie eine Anfrage aus einer Web-Oberfläche entgegennehmen, an ein Sprachmodell weiterleiten und die Antwort wieder im Browser anzeigen.
