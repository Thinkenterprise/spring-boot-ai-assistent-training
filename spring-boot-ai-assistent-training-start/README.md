# Spring Boot AI Assistant Training

Dieses Repository enthält die Beispiele und Begleitdokumentation für eine praxisorientierte Schulung zur Entwicklung von AI-Assistenten mit Spring Boot und Spring AI.

Anhand eines Insurance-Use-Cases entsteht Schritt für Schritt ein AI-Assistent: von der ersten Chat-Anfrage über die Integration in eine Web-Anwendung bis zu Prompts, Tools, Memory, Retrieval Augmented Generation (RAG), Tests, Monitoring und Model Context Protocol (MCP).

Die Anwendung nutzt lokale AI-Modelle über Ollama. Dadurch kann der Kurs ohne direkten Zugriff auf einen proprietären Cloud-Anbieter durchgeführt werden.

## Autor

Michael Schäfer ist Executive Consultant bei msg Research, Autor und Trainer. Seit über 20 Jahren vermittelt er Themen rund um Java und Spring und beschäftigt sich intensiv mit der Entwicklung von Anwendungen auf Basis generativer AI.

## Voraussetzungen

- Java 21 oder höher
- Maven 3.9 oder höher
- Ollama mit einem lokal verfügbaren Sprachmodell
- Docker Desktop, wenn die im Training verwendeten Container gestartet werden sollen
- Eine Java-fähige Entwicklungsumgebung, zum Beispiel Visual Studio Code mit dem Extension Pack for Java und dem Spring Boot Extension Pack

Weitere Hinweise zum Setup stehen in [Foundation Setup](documentation/2-foundation/1-foundation-setup.md).
